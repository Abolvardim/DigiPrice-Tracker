تنظیمات DigiPrice

برای دریافت تاریخچه از GitHub Actions، یک Fine-grained token بساز که فقط به مخزن Abolvardim/DigiPrice-Tracker دسترسی داشته باشد و مجوزهای Actions: Read and write و Contents: Read and write داشته باشد.

توکن فقط در فضای ذخیره‌سازی محلی افزونه در همین مرورگر نگهداری می‌شود. آن را در چت یا جای دیگری ارسال نکن. برای لغو دسترسی، هر زمان می‌توانی توکن را از GitHub باطل کنی.
